# 每日英语

只在本机浏览器运行的个人英语学习工具。数据保存在浏览器 IndexedDB 中，不需要账号、服务器或云数据库。

## 启动

双击 `start.bat`。首次启动会安装依赖，之后会打开：

`http://127.0.0.1:5173`

关闭黑色命令窗口即可停止本地应用。再次双击启动后，原来的学习数据仍会保留。

## 功能

- 首页：今日三项计划、快速备忘、学习日期表和每日备份。
- 每日单词：导入 Word/PDF 词表、今日词单从 1 开始编号、查看全部词库、按掌握状态分类、补记历史学习日期、完成每日目标后解锁四选一单词测试，并可按指定词或全部词生成 Word 默写卷。
- 口语：每日话题、导入 Word/PDF 素材、录制与回放、自我评分和练习笔记。
- 复习：按遗忘节奏生成复习队列，也可以按“还不熟 / 有印象 / 已经认识”分类复习。
- 备份：本地保留最近 14 天的每日快照，同时支持下载完整 JSON 备份与恢复。

所有文字型 PDF 都可以导入；扫描图片型 PDF 不含可复制文字，暂不支持。

## 测试

先构建并运行全部自动化验收测试：

`npm run test:all`

## 季节光感

页面会根据当前日期自动使用季节背景：

- 3–5 月：春季
- 6–8 月：夏季
- 9–11 月：秋季
- 12–2 月：冬季

背景只用于视觉表现，不包含天气数据或天气图标。

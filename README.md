# 每日英语

只在本机浏览器运行的个人英语学习工具。数据保存在浏览器 IndexedDB 中，不需要账号、服务器或云数据库。

## 启动

双击 `start.bat`。首次启动会安装依赖，之后会打开：

`http://127.0.0.1:5173`

关闭黑色命令窗口即可停止本地应用。再次双击启动后，原来的学习数据仍会保留。

## 第一版功能

- 首页：今日计划、快速备忘、四个模块的摘要。
- 每日单词：导入 Word/PDF 词表、逐词学习、学习状态、Word 默写卷导出。
- 口语：每日话题、录制与回放、自我评分和练习笔记。
- 阅读：内置文章、词汇点选、重点句与笔记、阅读理解题。
- 复习：按遗忘节奏生成复习队列并记录结果。

所有文字型 PDF 都可以导入；扫描图片型 PDF 不含可复制文字，暂不支持。
